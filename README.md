# Aeronautics X Block Displays (AXBD)

AXBD is a NeoForge mod for Minecraft 1.21.1 that makes display entities practical to build with and allows them to follow Create: Aeronautics sub-levels smoothly.

## Features

- Attach block, item, and text displays to moving Aeronautics sub-levels.
- Smooth display movement and rotation while the attached sub-level is moving.
- Create and select displays with the Display Editor.
- Move, rotate, and scale displays with interactive gizmos.
- Switch between world and local gizmo axes.
- Change the block used by selected block displays.
- Adjust position, rotation, scale, lighting, billboard mode, shadows, and view range.
- Copy, cut, paste, duplicate, delete, undo, and redo display edits.
- Use configurable movement, rotation, and scale steps.

## Requirements

- Minecraft 1.21.1
- NeoForge 21.1.257 or newer
- Create 6.0.10
- Create: Aeronautics and Sable for sub-level attachment support

Create and the Aeronautics-related mods are optional at load time, but they are required for the corresponding compatibility features.

## Building from source

Install JDK 21, clone this repository, and run:

```powershell
./gradlew build
```

The built mod will be available in `build/libs`.
